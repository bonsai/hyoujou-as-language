# 表情VLM 実験計画

## 研究質問

1. VLMは目・眉・口・視線・頭部の動きを、映像に根拠を置いて記述できるか。
2. 単一フレームと短い時系列フレームで、動きや変化の記述に差があるか。
3. 文脈や音声を追加すると、解釈の精度と過剰な断定はどう変化するか。
4. VLMは観察事実と感情・意図の仮説を区別できるか。
5. 同じ入力・設定で出力はどの程度再現されるか。

## 仮説（未検証）

- 顔パーツの動きと解釈を別々に採点すると、誤りの種類が明確になる。
- 時系列情報は、静止画では捉えにくい変化や同期の記述に役立つ可能性がある。
- 文脈追加は解釈を助ける一方、文脈に引きずられた過剰推論も生む可能性がある。

## MVP

- 利用許諾または本人の同意を確認した短い動画を少数用意する。
- 個人特定を目的とせず、必要最小限のデータだけを扱う。
- 目、眉、口、視線、頭部の観察項目と時間範囲を人間が注釈する。
- 同じタスクをVLMに実行させ、出力をJSONLで保存する。
- 人間の注釈と照合し、誤りと不確実性の扱いを評価する。

## 比較条件

- A：単一フレーム
- B：時間順の複数フレーム
- C：時間順の複数フレーム + 利用可能な音声情報
- D：時間順の複数フレーム + 明示された状況説明

モデルが直接扱えないモダリティを変換する場合、変換手順を記録する。

## 評価対象

- 観察記述の正確さ
- 時間範囲と動作順序
- 根拠フレームとの対応
- 根拠のない感情・意図の断定
- 曖昧な例を保留する適切さ
- 同一設定での出力安定性
- 処理時間とコスト

## 実験記録

データ版、出典・同意条件、対象区間、モデル名・版、プロンプト版、フレーム抽出方法、音声の有無、生成設定、実行日時、出力、評価結果、失敗例を保存する。

## 成功条件

モデルの感情推定を正しいと仮定するのではなく、観察記述と解釈仮説を区別して比較でき、別の人が手順を再実行できること。
