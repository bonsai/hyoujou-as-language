# 表情オントロジー（初期案）

このオントロジーは、顔の動きとその解釈を混同しないための初期語彙である。必要に応じて、注釈例と評価結果に基づき更新する。

## 1. 観察可能な要素

### 目・まぶた
- 開き具合の変化
- まばたき
- 視線の方向と移動
- 左右の差異（観察可能な場合）

### 眉
- 上下の移動
- 内側・外側の動き
- 左右差
- 変化の開始・終了

### 口・唇・顎
- 口の開閉
- 口角の移動
- 唇の形状変化
- 顎の動き
- 発話・歌唱との時間的な対応（音声がある場合）

### 頭部・顔の向き
- 左右への回転
- 上下への傾き
- 前後の移動
- 視線との協調・不一致

### 時間構造
- 開始、ピーク、終了
- 持続時間
- 反復
- 他の顔パーツや音声との同期
- 変化が滑らかか、急激か

## 2. 解釈レイヤー

観察項目とは別に、次のような解釈仮説を記録できる。

- 会話上の機能（例：応答、強調、ためらいの可能性）
- 表現上の機能（例：キャラクター演技、演出的な誇張）
- 感情に関する仮説
- 社会的・文化的な慣習に関する仮説
- 解釈不能、または複数の解釈が可能という判断

これらは顔の動きだけから確定しない。文脈が推定に影響した場合は、使った文脈も記録する。

## 3. 表現を構成する複数モダリティ

VTuberやアニメーションでは、表情は顔だけで完結しないことがある。

- 顔：目、眉、口、頭部
- 手：ジェスチャー、顔との位置関係
- 身体：姿勢、動作、タイミング
- 音声：発話、声色、歌唱、間
- 環境：カメラ、照明、背景、画面上の演出

モダリティごとの観察と、モダリティ間の同期を別々に記録する。

## 4. 注意点

- 笑顔を幸福の確証とみなさない。
- 視線を意図や注意の確証とみなさない。
- 文化差や個人差を無視して普遍的な意味を割り当てない。
- 手話やその他の言語的表現を、単なる表情・身振りに還元しない。
- 顔の動きの記述と、本人の内面についての主張を明確に分ける。
