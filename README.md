# 表情は言語である — Hyoujou as Language

顔の動きを、意味を伝える構造として観察・記述・評価する研究プロジェクト。表情を単一の感情ラベルに還元せず、顔の各部位、時間変化、文脈、解釈の不確実性を分けて扱う。

## 研究目的

- 目・眉・口・視線・頭部の動きを一貫した形式で記述する。
- 複数の顔パーツの組み合わせと時間的な変化を扱う。
- 観察できる動作と、感情・意図についての解釈を分離する。
- VLMが顔の動きを根拠に基づいて説明し、不確実性を適切に表せるか評価する。
- VTuberの表情、口パク、視線、手振り、音声、環境の同期研究につなげる。

## 基本モデル

**観察 → 構造化 → 解釈仮説 → 評価**

1. 顔の各部位の動きや視線を観察する。
2. 時刻とともに構造化する。
3. 感情・意図・会話上の機能などを、確定事実ではなく仮説として記録する。
4. 人間の注釈とVLMの出力を比較し、正確さと過剰解釈を評価する。

## 原則

- 表情から内面の感情を確定したと扱わない。
- 文化、状況、個人差を考慮し、単一の意味に決めつけない。
- 観察の根拠となる時間範囲を記録する。
- 同意、プライバシー、データの利用許諾を確認する。
- 実験結果が出るまでは、仮説を実証済みの結論として表現しない。

## MVP

まずは利用条件を確認した少数の短い動画または同意を得た録画で、目・眉・口・視線・頭部の観察記述を作成する。VLMの説明を構造化して保存し、人間の注釈と比較する。顔認識による個人特定や、表情からの心理状態の断定は目的としない。
